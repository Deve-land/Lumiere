# Lumière - فروشگاه شمع‌های دست‌ساز

یک وب‌سایت زیبا و مدرن برای فروشگاه شمع‌های دست‌ساز Lumière با طراحی احساسی و کاربرپسند.

## ویژگی‌ها

### 🎨 طراحی و رابط کاربری
- **طراحی مدرن و زیبا**: استفاده از رنگ‌های سفید و سبز ملایم (#A3B18A)
- **طراحی واکنش‌گرا**: سازگار با تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ)
- **انیمیشن‌های نرم**: افکت‌های بصری جذاب و تعاملی
- **فونت فارسی**: استفاده از فونت Vazirmatn برای خوانایی بهتر

### 📱 بخش‌های اصلی
1. **هدر سایت**: لوگو Lumière و منوی ناوبری
2. **بخش قهرمان**: تصویر شمع روشن با متن احساسی
3. **دسته‌بندی‌ها**: رایحه‌ای، مناسبتی، شکل و رنگ
4. **محصولات ویژه**: نمایش 4 محصول با قابلیت افزودن به سبد
5. **نظرات مشتریان**: بازخوردهای احساسی
6. **چرا ما؟**: ویژگی‌های خاص محصولات
7. **فوتر**: اطلاعات تماس و شبکه‌های اجتماعی

### ⚡ قابلیت‌های تعاملی
- **منوی موبایل**: همبرگر منو برای دستگاه‌های کوچک
- **اسکرول نرم**: حرکت آرام بین بخش‌ها
- **سبد خرید**: قابلیت افزودن محصولات با نمایش تعداد
- **اعلان‌ها**: پیام‌های موفقیت برای کاربر
- **انیمیشن‌های ورود**: افکت‌های بصری هنگام اسکرول

## ویژگی‌های فنی

### HTML
- ساختار معنایی و دسترسی‌پذیر
- متا تگ‌های بهینه برای SEO
- پشتیبانی از RTL (راست به چپ)

### CSS
- Flexbox و Grid برای چیدمان
- متغیرهای CSS برای رنگ‌ها
- انیمیشن‌های CSS برای افکت‌های بصری
- Media Queries برای طراحی واکنش‌گرا

### JavaScript
- ES6+ syntax
- Event Listeners برای تعامل
- Intersection Observer برای انیمیشن‌های اسکرول
- Local Storage برای ذخیره داده‌ها
